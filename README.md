# Selenium_Lab3

Лабораторна робота №3, варіант 4 – автоматизоване тестування сторінок сайту
https://the-internet.herokuapp.com/ за допомогою Selenium WebDriver (C#, NUnit, Chrome).

Сторінки: Add/Remove Elements, Checkboxes, Dropdown, Inputs, Status Codes,
Drag and Drop, Shifting Content, Geolocation, JavaScript Errors, Exit Intent.

Запуск: `dotnet test` або Test Explorer у Visual Studio.
Після кожного тесту зберігається скріншот у `SeleniumTests/bin/Debug/net9.0/Screenshots`.
